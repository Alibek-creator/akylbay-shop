AKYLBAY SHOP — ГОТОВЫЙ САЙТ

Файлы:
- index.html — структура сайта
- styles.css — дизайн и адаптивность
- script.js — каталог, фильтры, корзина и заказ через WhatsApp

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом.
3. Сайт работает сразу, сервер не нужен.

ЧТО ОБЯЗАТЕЛЬНО ИЗМЕНИТЬ
1. Откройте script.js.
2. Найдите строку:
   const WHATSAPP_NUMBER = "77000000000";
3. Замените 77000000000 на реальный номер магазина без плюса и пробелов.
   Пример: 77771234567

КАК ИЗМЕНИТЬ ТОВАРЫ
В начале script.js находится массив products.
Для каждого товара можно менять:
- name — название
- price — цена
- description — описание
- sizes — размеры
- category — категория
- badge — плашка
- type — тип рисунка товара

КОНТАКТЫ
Номер телефона, email, Instagram и TikTok находятся внизу файла index.html.

ПУБЛИКАЦИЯ
Сайт можно загрузить на GitHub Pages, Netlify, Vercel или обычный хостинг.
